### 🚀 Öne Çıkan Proje: Pusula

* **Proje Adı:** Pusula – YKS & LGS İnteraktif Çalışma Asistanı
* **Canlı Sürüm:** [pusulaapp.com.tr](https://www.pusulaapp.com.tr)
* **Açıklama:** Öğrencilerin sınav hazırlık süreçlerini optimize etmek, çalışma programlarını takip etmek ve verimliliklerini artırmak amacıyla geliştirdiğim interaktif bir web platformu.
* **Mimari & Teknolojiler:** 
  * **Frontend:** React ve Tailwind CSS ile modern, hızlı ve responsive kullanıcı arayüzü.
  * **Backend & Veritabanı:** Supabase altyapısı (PostgreSQL veritabanı, güvenli Google OAuth 2.0 kimlik doğrulama).
  * **Sürüm Kontrolü & Yayın:** GitHub üzerinde versiyonlanan kurumsal kod tabanı ve Vercel CI/CD entegrasyonu ile kesintisiz canlı yayın.

### 🤖 Otomasyon & Discord Botları

* **Node.js** ve JavaScript ekosistemini kullanarak topluluk yönetimi, sunucu otomasyonu ve özel API entegrasyonları içeren işlevsel **Discord botları** geliştiriyorum.
* Asenkron programlama, sunucu tabanlı veri yönetimi ve bot güvenliği konularında pratik deneyime sahibim.
